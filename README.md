# Actividad_laboratorio_semana2

## Estructura de carpetas y conexión con Obsidian

Para mantener la contextualización y una gestión eficiente de los archivos, el vault de Obsidian se aloja directamente dentro del directorio raíz del proyecto. Estructura:

```
/Actividad_laboratorio_semana2
│
├── /docs_obsidian          # Vault de Obsidian para la gestión del conocimiento y contexto
│   ├── 01_Investigacion    # Notas sobre el MCP y el desarrollo de la integración
│   ├── 02_Prompts          # Registro de los prompts utilizados
│   └── 03_Configuracion    # Pasos de instalación y despliegue
│
├── /src                    # Scripts para conectar la IA con AutoCAD (Python/AutoLISP)
│
├── /cad_files              # Archivos .dwg (Bocetos 2D y modelos 3D)
│
└── README.md               # Documentación principal del repositorio
```
